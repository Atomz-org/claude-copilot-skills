Prepare the current work for delivery.

1. Confirm the branch follows the repository convention.
2. Run the repository checks and review the diff.
3. Ensure the change is documented, scoped, and safe to merge.
4. If the change is intended to be reused by another repository, confirm the submodule contract is still intact.
5. Summarize the release notes, risks, and verification evidence.
