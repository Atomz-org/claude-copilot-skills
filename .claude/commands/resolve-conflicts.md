Resolve merge conflicts safely.

1. Inspect conflict state and list conflicted files.
2. For each conflict, explain both intents and chosen merge resolution.
3. Apply resolution without adding unrelated behavior.
4. Run project checks.
5. Stage and continue merge/rebase.
6. Summarize trade-offs and remaining risk.
